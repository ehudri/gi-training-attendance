# נוכחות בהדרכות צוות – המכון לגסטרואנטרולוגיה

מערכת פשוטה לרישום נוכחות בהדרכות: המשתתפים סורקים קוד QR, נכנסים עם Google (או נרשמים ידנית), והנוכחות נרשמת אוטומטית בגיליון Google.

- **דף ניהול:** `https://ehudri.github.io/gi-training-attendance/admin/`
- **גיליון הנתונים:** נפתח מכפתור "פתיחת הגיליון" בדף הניהול

---

## איך פותחים הדרכה

1. נכנסים לדף הניהול ומתחברים עם Google.
2. לוחצים **"+ הדרכה חדשה"**.
3. ממלאים שם/נושא, תאריך (ברירת המחדל: היום), קטגוריה, ומדריך/ה (לא חובה).
4. לוחצים **"יצירת הדרכה והצגת QR"** – קוד ה-QR מוצג מיד.

הרישום פתוח **רק ביום ההדרכה** (לפי שעון ישראל). אפשר לפתוח או לסגור ידנית עם המתג שליד כל הדרכה, ולחזור למצב אוטומטי בלחיצה על "חזרה לאוטומטי".

## איך מציגים את ה-QR

ברשימת ההדרכות לוחצים **QR** ליד ההדרכה. בחלון שנפתח:

- **מסך מלא למקרן** – קוד גדול על כל המסך, עם מונה נרשמים שמתעדכן. יציאה: Esc או ×.
- **הדפסה** – דף A4 עם הכותרת וה-QR, לתלייה בכניסה.
- **העתקה** – מעתיק את הקישור, לשליחה בווטסאפ או במייל.

## מה רואים המשתתפים

- **כניסה עם Google:** בפעם הראשונה מתבקשים פעם אחת שם מלא, תפקיד ומספר עובד. מהפעם השנייה – לחיצה אחת.
- **"אין לי חשבון Google – רישום ידני":** שם, תפקיד ומספר עובד.
- מספר העובד הוא המזהה של כל אדם. מי שנרשם פעם עם Google ופעם ידנית עם אותו מספר – נחשב אותו אדם.
- רישום כפול לאותה הדרכה מציג "כבר נרשמת" ולא נספר פעמיים.
- לא נאסף מספר תעודת זהות ואין מידע על מטופלים.

## איך מתקנים טעויות

- **מישהו נרשם בטעות / להדרכה הלא נכונה:** בדף הניהול → **משתתפים** → **הסרה** ליד השם.
- **מישהו לא הצליח להירשם:** משתתפים → "הוספת משתתף/ת ידנית" → מספר עובד (אם הוא חדש – גם שם ותפקיד). מנהלים יכולים להוסיף גם כשהרישום סגור.
- **שם או תפקיד שגויים:** מתקנים בלשונית **"עובדים"** בגיליון, ואז בדף הניהול לוחצים **"בנייה מחדש של נוכחות"** כדי שהכותרות יתעדכנו.
- **מישהו ערך ידנית את לשונית "נוכחות" ושבר אותה:** **"בנייה מחדש של נוכחות"** (בדף הניהול, או בגיליון: תפריט *נוכחות הדרכות* ← *בנייה מחדש*). הלשונית נבנית מחדש מתוך "יומן", "עובדים" ו"הדרכות".

> כל רישום והסרה נשמרים בלשונית **"יומן"** ואינם נמחקים לעולם. לא עורכים את "יומן" ידנית.

## איך מוסיפים מנהל/ת

1. פותחים את הגיליון ← לשונית **"הגדרות"**.
2. בעמודה **"מיילים של מנהלים"** מוסיפים בשורה ריקה את כתובת ה-Gmail של המנהל/ת.
3. זהו. בכניסה הבאה לדף הניהול תהיה לו/ה גישה.

באותה לשונית אפשר גם להוסיף **קטגוריות** חדשות (מעבר לבטיחות ומקצועי) ו**תפקידים** לרשימת הבחירה.

## מבנה הגיליון

| לשונית | תוכן |
|---|---|
| נוכחות | שורה לכל הדרכה, עמודה לכל עובד/ת (שורה 1: שם, שורה 2: מספר עובד), V = נכח/ה |
| יומן | רישום גולמי של כל פעולה (זמן, הדרכה, עובד/ת, שיטה, רישום/ביטול) |
| עובדים | מאגר העובדים: מספר עובד, שם, תפקיד, מייל, מזהה Google |
| הדרכות | פרטי כל הדרכה ומצב הרישום (אוטומטי/פתוח/סגור) |
| הגדרות | קטגוריות, מנהלים, OAuth Client ID, תפקידים |

## לצוות הטכני

- **Frontend:** HTML/CSS/JS סטטי ב-GitHub Pages. ההגדרות (כתובת ה-Web App ו-Client ID) בקובץ `config.js` בלבד.
- **Backend:** `apps-script/Code.js` – Google Apps Script שמחובר לגיליון. עדכון קוד: `apps-script/deploy.sh` (דורש `clasp login`). הכתובת של ה-Web App נשארת זהה.
- **אימות:** ה-ID token של Google נבדק בשרת מול `oauth2.googleapis.com/tokeninfo` כולל התאמת `aud` ל-Client ID. כל כתיבה לגיליון נעשית תחת `LockService`.
- **OAuth Client ID:** ב-Google Cloud Console, מסוג Web application. ב-Authorized JavaScript origins: כתובת האתר ב-GitHub Pages ו-`http://localhost:8000` לבדיקות.
